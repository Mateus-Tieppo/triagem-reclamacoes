# Direção visual

**Público:** primeiro o recrutador que abre o link do portfólio, muitas vezes pelo celular e com poucos minutos; depois o time de atendimento que usaria a ferramenta no dia a dia.

**Tom:** ferramenta de trabalho real, quente e cuidadosa, longe da cara de dashboard genérico de IA.

**Escolha:** entre três direções mostradas lado a lado (etiqueta de expedição, central noturna escura e relatório editorial), o Mateus escolheu a **etiqueta de expedição**. Ela conversa com o problema, que é logística e entrega, e é a mais fácil de lembrar.

**Ideia marcante:** cada fila tem um código de três letras impresso como etiqueta (ENT, FAL, ERR, DEF, EST, ATD, COB, OUT) e o que vai para revisão humana ganha um carimbo.

**Paleta:** papel creme, tinta grafite, amarelo de etiqueta e vermelho tijolo para revisão, com versão escura. Todos os pares de texto passam AA.

**Fontes (Google Fonts):** Archivo, com o eixo de largura para títulos condensados e para a marca, e IBM Plex Mono só para códigos e números.

Detalhes de tokens, forma e movimento em [`web/DESIGN.md`](../web/DESIGN.md).
